# Security Policy

We take security seriously.

## Reporting a Vulnerability

If you discover a security issue or a bug that could have security implications, please **[open an issue on GitHub](https://github.com/2ndbrainlabs-ai/synapse-cli/issues/new/choose)** and tag it with the `security` label.

For sensitive reports that should not be public, email **security@2ndbrainlabs.ai** instead. We aim to acknowledge reports within 72 hours.

## Supported Versions

Only the latest published release on npm is supported for security fixes.

## Scope

This policy covers the `@2ndbrainlabs-ai/synapse-cli` npm package and its source in this repository. Generated MCP server files are user-owned and out of scope — audit them before running.
